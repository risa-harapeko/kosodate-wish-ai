# イライラから本当の願いを発見するAI（仮）

> 「イライラ」は、大切にしたい何かが満たされていないサイン。
> その裏にある **本当の願い** を、AIとの対話で一緒に見つけるサービスです。

---

## どんなサービス？

| 項目 | 内容 |
| --- | --- |
| ターゲット | 仕事と子育てを両立するワーママ |
| できること | イライラした出来事を書くと、AIが問いかけながら「本当はどうしたかったのか」を一緒に見つけてくれる |
| コンセプト | 「イライラを消す」のではなく「イライラから自分を知る」 |

## 進め方：小さく作って、少しずつ足す

いきなり全部は作らず、**1ステップで1つずつ** 機能を足していきます。
各ステップの終わりに自分で数日使ってみて、次に進みます。

| ステップ | できるようになること | 状態 |
| --- | --- | --- |
| 1. AIと話せる | イライラを書くと、AIが問いかけて本当の願いをまとめてくれる | 完成 |
| **2. 行動を提案する** | 願いがわかったあと、「休む」「手放す」などの小さな行動を2〜3個提案する | 作成中 |
| 3. 記録を残す | 対話の結果（日時・場面・イライラ度・願い・行動）をCSVファイルに保存し、履歴を見られる。イライラ度は話す前と後に5段階で自己評価する | |
| 4. ふりかえる | よく出る願いや、イライラしやすい場面をグラフで見られる。週ごとに傾向と対策をAIがまとめる | |
| 5. 他の人に使ってもらう | ネットに公開し、パスワードを知っている人だけが使えるようにして、ワーママ数名に試してもらう | |

ステップ1〜4は自分のパソコンで自分だけが使います。

## ステップ1で作るもの

チャット形式の **1画面だけ** です。保存もログインもありません。

1. イライラした出来事を入力して送る
2. AIがまず気持ちを受け止め、問いを1つ返す
3. 答えると、AIが次の問いを返す（数回くり返す）
4. 最後にAIが「あなたは本当は〜を大切にしたかったのかもしれません」とまとめる
5. 「新しく話す」ボタンで会話をリセットできる

**AIへの指示（プロンプト）に入れること**

- まず共感する。イライラしたことを否定しない
- 問いは1回に1つ、短く
- 説教しない。「母親なのだから」などと言わない
- 願いは断定せず「〜かもしれません」と提案し、本人に確かめる
- 危険な兆候があれば深掘りを止め、相談窓口を案内する

**完成の目安**

- [ ] 自分のパソコンで画面が開き、AIと会話できる
- [ ] 実際のイライラを3回書いてみて、うち2回以上「そうかも」と思えるまとめが出る
- [ ] AIが説教したり、一度にたくさん質問したりしない

## 使う道具

| 道具 | 役割 | 使い始めるステップ |
| --- | --- | --- |
| Python | プログラムを書く言語 | 1 |
| Streamlit | Pythonだけで画面を作れる道具 | 1 |
| Claude API | AIとの会話を担当する（使った分だけ料金がかかる） | 1 |
| CSVファイル | 記録の保存（Excelでも開ける） | 3 |

## ファイル構成（ステップ1）

```
kosodate/
├── README.md       # このファイル
├── app.py          # 画面とAIとの会話（最初はこの1ファイルだけ）
├── requirements.txt  # 使う道具の一覧（streamlit, anthropic, python-dotenv）
└── .env            # APIキーを書く（人に見せない・共有しない）
```

フォルダを分けたりデータベースを使ったりするのは、必要になってからにします。

## どのステップでも守ること

1. **危険な兆候への対応**：「消えたい」「子どもを叩いてしまいそう」などが出たら、AIは深掘りを止めて相談窓口（児童相談所「189」、よりそいホットラインなど）を案内する
2. **医療ではないことの表示**：「これはセルフケアのツールで、医療やカウンセリングの代わりではありません」と画面に書く
3. **APIキーを外に出さない**：APIキーは `.env` に書き、コードの中や人に見せる場所には書かない

※ 相談窓口の電話番号と受付時間は、公開前（ステップ5）に公式サイトで確認します。
